# Host tests

`make test`, or `tests/run.sh`, or `tests/run.sh paging` for one.

Each test links the **real** firmware module it exercises. The stubs in
`tests/stub/` stand in only for what a host has no answer for — the
Pico SDK, FatFs, and whichever peripherals a given test is not about —
so what is asserted is the shipping code's behaviour, not a copy of it.
ROM images are linked by the same `IMPORT_BIN` the firmware uses, so
the paging tests compare against the actual bytes on the board.

Fixtures are generated by `tests/mkfixtures.py` rather than committed,
so the shape of each one is readable next to what a test claims about
it. `tests/out/` holds anything a test drew, as PPM, for looking at.

| test     | what it covers |
|----------|----------------|
| `paging` | all eight machines' memory maps and port decodes, and the PSRAM bank staging |
| `fdc`    | the +3's uPD765 over standard and extended `.dsk`, and write-back |
| `beta`   | the Beta Disk's WD1793 over `.trd`, and write-back |
| `media`  | `.zip` listing and extraction, Timex `.dck` cartridges |
| `divmmc` | the automap, the bank paging, and the SD card behind it |
| `tape`   | `.tap`, `.tzx` and `.pzx` arriving at the same bytes |
| `saa`    | the SAA1099: its pitch law across the octave range, mixer, envelopes and clock scaling |
| `video`  | the Bayer dither and every table built on it |
| `ui`     | the rasteriser, the font, and the rounded frames |

## Not covered here

The clock engine and the bus inference need the real Z80; the pace
floor probe on the board is their test. USB (keyboard, MSC) is TinyUSB
against real hardware. Audio output is a DMA ring with nothing to
assert on a host.
